# 模型提示词适配格式

只读取用户指定模型对应的部分。无法确定具体界面时，使用中文通用自然语言格式，不添加可能不受支持的语法。描述性提示词默认使用中文。

## 通用自然语言格式

写成结构清楚的连续描述，顺序为：主体与关系 → 场景与空间 → 构图与镜头 → 光影与色彩 → 材质与风格 → 关键细节与排除项。

- 将最决定辨识度的信息放在开头。
- 使用完整空间关系，不堆叠孤立标签。
- 准确外文文案、品牌名、产品名和参数语法保持原样。
- 没有平台依据时，不添加权重、种子、版本号或采样参数。

## OpenAI Image

- 使用清楚的中文自然语言，明确对象、位置、动作和对象之间的关系。
- 对编辑任务分别说明“保持不变”和“需要改变”的内容。
- 将准确文案放入引号并说明排版；直接写出“不要水印、不要应用界面”等排除要求。
- 不附加 Midjourney、Stable Diffusion 或其他平台的参数语法。
- 多轮编辑时，每轮只改变用户指定内容，重申必须锁定的主体特征和构图。

## Midjourney

- 使用按重要程度排列的紧凑中文短句，参数语法保留英文。
- 图片或用户明确要求画幅时，使用 `--ar W:H`。
- 仅用 `--no` 排除少量明确的多余元素；复杂排除要求直接写入主体描述。
- 不自行添加版本号、随机种子、风格化数值、chaos、quality 或风格参考参数。
- 用户提供风格参考图或参数时原样保留，不猜测引用地址。
- 文字画面要说明内容和排版，并提醒关键文案通常需要后期校对。

## FLUX

- 使用细致的中文自然语言，将主体、数量、空间关系和构图置于审美修饰词之前。
- 通过清晰句子描述材质、光照和文字，不默认使用标签串。
- 只有具体界面提供负面提示词功能时才单独输出；否则把排除要求写进正向描述。
- 不知道界面是否支持时，不使用括号权重、LoRA、ControlNet 或采样参数。

## Stable Diffusion / SDXL

- 分别提供中文正向提示词和中文负面提示词。
- 正向按主体、场景、构图、光线、色彩、材质和风格分组；负面只放需要排除的缺陷和错误内容。
- 只有用户明确要求或已提供工作流信息时，才使用权重、LoRA、嵌入、ControlNet 或区域提示语法。
- 不知道用户界面和模型检查点时，不擅自指定采样器、步数、CFG、分辨率或高分修复设置。
- 若用户使用图生图，建议把提示词控制在可辨识差异上，不重复描述已由参考图稳定锁定的低价值细节。

## 即梦、可灵、豆包等中文自然语言工具

- 使用流畅、短而明确的中文句子。
- 明确主体数量、相对位置、镜头角度、光线方向和色彩方案。
- 不使用未验证的权重、括号、版本号或英文标签堆砌。
- 界面支持时，将画幅、分辨率和参考强度放在参数区，不混入画面正文。
- 对视频首帧或图生视频用途，额外固定人物朝向、肢体状态、视线和可供运动延展的空间。

## 可直接复制的输出规则

### 用户只要求提示词

只返回一个含最终中文提示词的代码块，不添加前言、分析或使用说明。

### 用户要求完整反推

依次返回图片拆解、高还原提示词、必要的负面提示词、模型适配与参数。分析放在代码块外；提示词内不得保留“[主体]”“[风格]”等占位符。
