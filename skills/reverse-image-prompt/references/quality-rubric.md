## 使用方法

仅在复杂图片、高精度要求、多图融合、文字海报或提示词校准时完整使用。先写初稿，再逐项评分；低于 85 分时只针对失分项重写一次，不向用户默认展示评分。

## 评分细则

### 1. 主体、数量、动作与关系：25 分

- 主体类别与数量准确：8 分
- 决定性外形、服装或结构准确：6 分
- 动作、表情、朝向和视线准确：5 分
- 主体间前后、左右、遮挡和互动准确：6 分

### 2. 构图、位置、占比与画幅：20 分

- 画幅与取景范围一致：4 分
- 主体坐标和视觉占比明确：7 分
- 留白、平衡、引导线和层次准确：5 分
- 机位、透视和焦点表现合理：4 分

### 3. 光影、色彩与氛围：15 分

- 主光方向、软硬与明暗比明确：5 分
- 主辅色、强调色和冷暖关系准确：5 分
- 环境效果和整体调色一致：5 分

### 4. 风格、媒介、材质与纹理：15 分

- 媒介或渲染方式判断准确：5 分
- 关键材质与表面特征绑定到对象：6 分
- 颗粒、笔触、噪点和空气质感有效：4 分

### 5. 文字、图形和截图元素：10 分

- 清晰文字准确抄录并说明排版：4 分
- 字体特征、层级和对齐清楚：3 分
- 正确处理水印、状态栏、按钮和其他附带界面：3 分

### 6. 模型格式与可执行性：10 分

- 使用目标模型支持的表达和参数：4 分
- 提示词可直接复制，无占位符或分析语句：3 分
- 信息按重要度排列，约束靠近对应对象：3 分

### 7. 无幻觉、无冲突、无无效堆词：5 分

- 不虚构身份、品牌、设备、艺术家或技术参数：2 分
- 光线、空间、动作和风格无内部矛盾：2 分
- 没有重复的质量形容词：1 分

## 一票否决项

出现任一项就先修正，不计算总分：

- 主体数量错误或主次颠倒。
- 左右、前后、朝向或遮挡关系颠倒。
- 改掉用户要求锁定的主体、构图、文案或风格。
- 把截图界面误当作核心内容，或误删用户明确要求保留的界面。
- 最终提示词仍有占位符、分析语气或不支持的参数语法。
- 将无法辨认的信息、未知人物身份或不存在的品牌写成确定事实。

## 常见失败与修正

| 失败表现 | 原因 | 修正方式 |
| --- | --- | --- |
| 形容词很多但不像原图 | 没抓住 A 级信息 | 把主体数量、剪影、位置、动作和主构图移到开头 |
| 人物或产品属性串位 | 属性离对象太远 | 将颜色、材质、服装等紧跟对应对象 |
| 画面元素齐全但布局错误 | 只列清单，没有空间关系 | 使用左/中/右、前/中/后、占比和遮挡关系 |
| 光线描述互相冲突 | 同时堆砌多种氛围词 | 保留一个主光逻辑，再写必要的补光与环境光 |
| 风格名称很响亮但不可执行 | 使用抽象标签或艺术家捷径 | 改写为线条、边缘、色块、纹理、渲染和调色特征 |
| 海报文字生成混乱 | 只写文案，没有排版规格 | 加入位置、层级、字号关系、对齐、颜色和换行 |
| 模型忽略重要元素 | 信息顺序不当或细节过载 | A 级信息前置，删除重复 C 级细节 |
| 多图参考互相污染 | 未分配每张图职责 | 明确图 1/图 2/图 3 各自提供什么，并声明冲突优先级 |

## 最终压缩规则

- 删除不改变可见结果的空泛词和同义重复。
- 一个对象的属性尽量放在同一句或相邻短句。
- 重要位置和数量至少明确一次，不用多种说法反复强调。
- 负面提示词只写实际风险，不罗列所有可能缺陷。
- 压缩后再次确认 A 级信息没有被删除或弱化。
